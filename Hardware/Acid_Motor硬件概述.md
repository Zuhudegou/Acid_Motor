# Acid_Motor 硬件设计概述

本文记录当前版本 Acid_Motor 控制板的硬件结构、关键参数和已经确认的问题。文中的器件型号、网络名称和阻容参数均以当前的嘉立创EDA工程 `旷世神作2.0.epro2` 为准，而不是沿用早期文档中的描述。

这块板目前仍属于实验版本。本文一方面说明我是怎样设计各个模块的，另一方面也把设计中需要修改的地方明确记录下来，避免后续调试时继续建立在错误结论上。

## 1. 整体结构

整块板可以分为以下几个部分：

| 模块 | 主要器件 | 作用 |
| --- | --- | --- |
| 母线输入与一级降压 | MP4583 | 将 `PVCC` 降为约 5 V |
| 模拟、数字电源 | 两颗 MP20051 | 将 5 V 分别降为 `AVCC` 和 `DVCC` |
| 主控制器 | STM32G431 | 运行电机控制算法、采样 ADC、输出 PWM |
| 板载调试器 | STM32F042 | 提供 USB、SWD 和串口调试功能 |
| 三相栅极驱动 | FD6288T | 将六路 PWM 转换为半桥 MOS 管的栅极驱动信号 |
| 三相逆变桥 | 6 颗 HYG080N10LS1C2 | 将直流母线转换为三相 PWM 电压 |
| 位置检测 | MA600 | 通过 SPI 向主控制器提供转子角度 |
| 模拟采样 | 分流电阻、内部运放、分压网络 | 采集相电流、母线电压和温度 |
| 通信接口 | SN65HVD230 | 提供 CAN 通信 |

电源关系可以简化为：

```text
PVCC
 ├─ U3 MP4583 ── 5V ── U14 MP20051 ── DVCC
 │                    └─ U15 MP20051 ── AVCC
 │
 └─ 三相 MOS 逆变桥 ── U/V/W 相线

STM32G431 ── PWM ── FD6288T ── MOS 栅极
STM32G431 ── ADC/SPI ── 电流、电压、温度和角度采样
```

## 2. 供电网络

### 2.1 母线输入

`PVCC` 是电机功率级和一级降压的共同输入。当前版本中，输入端直接连接到母线电容、MP4583 和三相上桥臂，没有保险丝、反接保护、浪涌限制和母线 TVS。因此，芯片能够承受多高的电压，并不等于整块板就能够在该电压下可靠工作。

当前输入侧和功率级存在以下限制：

- MP4583 和三相 MOS 管的标称耐压为 100 V；
- 输入侧部分陶瓷电容的耐压为 50 V；
- 自举二极管 1N5819W 的反向耐压只有 40 V；
- MOS 管开关时还会在母线上产生高于输入电压的尖峰；
- PCB 间距、铜厚、连接器和散热能力也会限制实际工作电压与电流。

所以，当前设计不能称为“100 V 电机驱动板”，也不适合直接按 40 V 母线长期使用。现阶段我应先按 24 V 等级进行验证，再根据实测尖峰和器件降额结果确定最终母线范围。

输入电容的图面值与实际料号还存在冲突。C1～C4、C33～C36 在工程中标成 $100\ \mathrm{\mu F}/50\ \mathrm{V}$，但所选料号 HGC1206R5106K500NSPJ 实际是 $10\ \mathrm{\mu F}/50\ \mathrm{V}$ 的 1206 陶瓷电容，单颗容量相差 10 倍。按现有料号计算，再加上 C5、C37，母线输入端的标称陶瓷电容总量约为 $100\ \mathrm{\mu F}$，而不是图面值暗示的 $820\ \mathrm{\mu F}$。陶瓷电容在较高直流偏压下还会进一步损失有效容量，下一版必须统一原理图数值、BOM 料号和实际装配器件。

### 2.2 一级降压：PVCC 转 5 V

U3 使用 MP4583GQVE-Z。它是一颗同步 Buck 芯片，开关频率约为 400 kHz，内部包含高、低侧开关管。

高侧开关管导通时，母线通过 `SW` 节点向 L1 送入能量，电感电流逐渐上升；高侧关断后，低侧同步开关管为电感电流提供续流路径。L1 与输出电容共同把高频开关波形转换成较稳定的直流电压。输出电压变化后，芯片通过 `FB` 引脚调节占空比，使反馈电压保持在内部参考值附近。

#### 输出电压计算

当前反馈电阻为：

- 上拉电阻 R26：$1\ \mathrm{M\Omega}$；
- 下拉电阻 R27：$191\ \mathrm{k\Omega}$；
- 反馈基准典型值：$V_{FB}=0.8\ \mathrm{V}$。

因此：

$$
V_{5V}=V_{FB}\left(1+\frac{R26}{R27}\right)
=0.8\left(1+\frac{1\ \mathrm{M\Omega}}{191\ \mathrm{k\Omega}}\right)
\approx4.99\ \mathrm{V}
$$

原文中的计算结果没有错，问题在于把 $1\ \mathrm{M\Omega}$ 简写成了 `1000`、把 $191\ \mathrm{k\Omega}$ 简写成了 `191`，没有写清单位，容易让人误以为阻值或公式有误。

$4.99\ \mathrm{V}$ 只是标称值，不是任意温度和器件误差下都精确不变的结果。把 MP4583 的反馈基准范围与两颗 1% 电阻的误差计入后，保守估算约为 4.83～5.15 V。实际结果还会受到纹波、布局和负载瞬态影响。

L1 为 $10\ \mathrm{\mu H}$，C22、C23 各为 $22\ \mathrm{\mu F}$。它们才是主要的储能与输出滤波器件。

#### C26 的实际作用

C26 是并联在 R26 两端的 $3.3\ \mathrm{pF}$ 前馈电容。它的容量极小，不负责在负载突变时向 5 V 电源补充能量。它会把输出端的高频变化耦合到 `FB`，改变反馈环路的高频响应。这个电容是否合适应结合数据手册、输出电容和环路稳定性进行确认，不能只根据“响应越快越好”来判断。

#### 当前结论

- 5 V 的反馈公式和标称结果正确；
- 原文对同步 Buck 的续流过程描述不完整；
- 原文对 C26 的作用解释错误；
- MP4583 的 100 V 耐压不能代表整块板的输入耐压。
- MP4583 的 NC1、NC9 当前悬空；官方建议将其接到功率地以改善散热，下一版需要一并处理。

### 2.3 二级降压：5 V 转 AVCC 与 DVCC

U14、U15 均使用可调输出的 MP20051 LDO：

- U14 输出 `DVCC`，用于 STM32 的数字电源、CAN 收发器和数字接口；
- U15 输出 `AVCC`，用于 STM32 的模拟电源、ADC 参考和 MA600 的模拟电源。

两路反馈电阻相同：上拉电阻为 $30.9\ \mathrm{k\Omega}$，下拉电阻为 $10\ \mathrm{k\Omega}$。输出电压为：

$$
V_{OUT}=0.8\left(1+\frac{30.9}{10}\right)
=3.272\ \mathrm{V}
$$

所以 `AVCC` 和 `DVCC` 的标称值约为 3.27 V，而不是严格的 3.30 V。这个电压仍处在 STM32 和 MA600 的正常供电范围内。

把模拟电源和数字电源分别稳压，可以减少数字负载电流直接通过模拟电源路径产生的压降和噪声。但两路电源仍来自同一个 5 V，地之间也通过 0 Ω 电阻相连，因此这只是电源与回流路径的分区，不是电气隔离。

#### 当前版本已经确认的问题

1. U14、U15 的裸露焊盘没有连接到各自的地。MP20051 的裸露焊盘既承担散热，也应按数据手册接地。
2. 两路 LDO 输出端没有按数据手册配置明确的本地 $4.7\ \mathrm{\mu F}$ 陶瓷电容。现有的 C28、C29 位于 5 V 输入侧，不是输出电容；`DVCC` 和 `AVCC` 上零散的 $100\ \mathrm{nF}$ 去耦也不能直接代替 LDO 要求的输出电容。
3. C29 是 U15 的输入旁路电容，但它当前接在 5 V 与 `DGND` 之间，而 U15 的地是 `AGND`。这会让 U15 的高频输入回流跨过地网连接，下一版应改为就近返回 `AGND`。
4. 下一版应在每颗 MP20051 的输入、输出引脚附近放置数据手册规定的陶瓷电容，并把裸露焊盘直接连接到对应地平面。

在这些问题修正之前，两路 3.27 V 电源可能出现启动异常、振荡或负载变化时电压不稳定，不能只因为万用表测得直流电压正常就认为电源没有问题。

LDO 的电流能力还受功耗限制。若从 5 V 降到 3.272 V 并输出 1 A，单颗 MP20051 的耗散约为：

$$
P=(5-3.272)\times1\approx1.728\ \mathrm{W}
$$

即使裸露焊盘正确接地，这个功耗也会带来很高的结温。因此，芯片标称的最大输出电流不能直接当作板上可持续电流使用，应根据实际负载、铜皮面积和温升重新核算。

### 2.4 地网络与 0 Ω 电阻

当前工程中的实际连接关系是：

```text
MPA_SM ── R1（0 Ω）── DGND ── R2（0 Ω）── AGND
```

其中：

- `MPA_SM` 是低侧功率回流和分流电阻的参考节点；
- `DGND` 是主控制器、栅极驱动器和数字电路的参考地；
- `AGND` 是 ADC、模拟前端和模拟电源的参考地。

0 Ω 电阻的主要作用是保留不同的网络名称，并在 PCB 上规定它们的连接位置。它便于我控制铺铜分区、回流路径和调试方式，但它本身不会阻止高频噪声，也不构成真正的隔离。

实际的 0 Ω 电阻、焊盘和走线都存在寄生电阻与寄生电感，因此两端的瞬态压差并不恒为零，可以近似写成：

$$
\Delta V\approx I R+L\frac{\mathrm{d}i}{\mathrm{d}t}
$$

如果功率电流错误地经过 R1、R2 或数字地回流，即使电阻标称为 0 Ω，也会把开关噪声带入 MCU 和 ADC。地的设计重点不是把网络名称分得越多越好，而是让大电流回路尽量短，并避免功率回流与模拟采样共用关键路径。

当前工程还存在命名和 PCB 实现不一致的问题：原理图中的 `PGND` 在 PCB 数据中对应 `MPA_SM`，容易在阅读和检查时被误认为两张不同的网；U2 的 `COM` 与驱动去耦 C41 实际接在 `DGND`，并不是直接接到功率地；PCB 虽然有 `AGND` 覆铜对象，但当前填充结果为空，实际主要依靠走线，不是原文所说的“独立模拟地平面”。下一版需要统一 `PGND/MPA_SM` 命名，并让栅极驱动脉冲电流以短、低电感路径回到低侧源极附近，避免它在安静的数字地中绕行。

## 3. 控制器、传感器与通信

### 3.1 主控制器 STM32G431

U4 是整块板的主控制器：

- `DVCC` 为 VDD、VBAT 等数字电源引脚供电；
- `AVCC` 为 VDDA、VREF+ 等模拟引脚供电；
- `DGND` 和 `AGND` 分别作为数字、模拟参考地；
- 定时器输出六路 PWM，ADC 采集电流、电压和温度，SPI 读取 MA600 角度。

这种供电分区与软件中的 ADC、PWM 和位置采样相对应，但最终精度仍取决于去耦、电源稳定性、地回流和采样时刻，不能仅靠网络名称保证。

当前 U4 的三组 VDD 和 VBAT 已配置四颗 $100\ \mathrm{nF}$ 去耦，但整个 MCU 仍缺少一颗就近的 4.7～10 µF 储能电容；VDDA 与 VREF+ 只有 C18 的 $100\ \mathrm{nF}$，还缺少约 $1\ \mathrm{\mu F}$ 的模拟参考去耦。U4 位于底层，而 C14～C18 位于顶层，VREF+/VSSA 的高频回路需要经过过孔，也不是高速 ADC 的理想布局。下一版应把模拟参考电容放到与 U4 同层并尽可能靠近对应引脚。

### 3.2 板载调试器 STM32F042

U1 通过 USB 与电脑通信，并向 U4 提供 SWD、串口和复位等调试信号。USB-C 接口的 VBUS 当前没有接入板上电源，因此 USB 只能提供通信，不能给控制板供电。

当前工程中，U1 的 VDD 接在 `DVCC`，但 VDDA 单独接到了名为 `3V3` 的网络。该 `3V3` 网络没有连接到任何电源，也没有本地去耦，意味着 U1 的 VDDA 实际处于悬空状态。这是一个明确的原理图错误。

下一版应按 STM32F042 的数据手册把 VDDA 接到有效的 3.3 V 电源，并在引脚附近放置去耦电容。由于 U1 的 VDD 已使用 `DVCC`，最直接的做法是让 VDDA 从 `DVCC` 经过 0 Ω 电阻或磁珠供电，并配置本地去耦。U1 的 VDD 本身也缺少明确的就近去耦，需要同时补上。

调试接口还存在可恢复性问题：U1 自己的 `IF_SWDIO`、`IF_SWCLK` 没有引出，U4 也没有独立的标准 SWD 接口。如果板载调试器未预先烧录或 U1 损坏，两颗 MCU 都很难重新下载。实验板至少应给两颗 MCU 各保留 SWDIO、SWCLK、NRST、GND 和目标电压测试焊盘。

### 3.3 MA600 磁编码器

U16 使用 MA600：

- `DVDD` 接 `DVCC`；
- `AVDD` 接 `AVCC`；
- SPI 与 STM32G431 通信；
- 器件底部裸露焊盘按数据手册要求保持悬空，不能把它和 MP20051 的裸露焊盘按同一种方式处理。

当前原理图没有给 MA600 明确配置独立的数字、模拟去耦电容。下一版应按数据手册补充 DVDD 的 $100\ \mathrm{nF}$ 和 AVDD 的 $1\ \mathrm{\mu F}$ 去耦，同时按手册保留传感器中心区域的元件净空。这里不能简单理解成“电容越贴近芯片中心越好”，而应在满足磁场测量净空的前提下缩短供电回路。

MA600 的 AVDD 来自以 `AGND` 为参考的 U15，但器件 GND 当前接在 `DGND`，模拟供电电流需要经过 R2 才能返回 U15。这使传感器的模拟电源和回流不在同一个本地域内。下一版需要统一 MA600 的供电参考地，并按数据手册重新检查 AVDD、DVDD 和 GND 的回路。

PCB 中 U16 位于板底中心，而两个分流电阻和高电流回流铜路距离传感器较近。MA600 直接测量磁场，附近的大电流路径也会产生磁场，因此这不仅是普通的电源噪声问题，还可能造成角度非线性。下一版需要让高电流路径远离传感器测量区域，并同时满足手册对磁性元件净空和去耦位置的要求；必要时可以把编码器单独做成小板。

MA600 已不适合用于新的长期量产设计，下一版选型时可以同时评估其替代型号；这不影响当前样板继续用于功能验证。

### 3.4 CAN 与 USB 接口

U12 使用 SN65HVD230，R22 为固定的 $120\ \Omega$ 终端电阻。CAN 总线只应在物理链路的两个末端各保留一个终端，因此固定终端适合末端节点，不适合所有节点。下一版可改为跳帽或可焊接选择。

当前 CAN 和 USB 接口均没有看到专用 ESD 保护；CAN 也没有共模电感或隔离。对于台架短线调试可以先使用，但如果线束较长、环境干扰较强或需要对外连接，应补充接口保护并重新检查布局。

PCB 规则中还把 MCU 侧的 `FDCAN1_RX`、`FDCAN1_TX` 错误设置成了差分对，而真正需要按差分信号处理的是 `CAN_H`、`CAN_L`；USB 的 D+、D− 也没有差分对规则。`FDCAN1_RX/TX` 只是收发器与 MCU 之间的两根单端逻辑线，不能因为外设名称中带有 FDCAN 就把它们当成差分线，SN65HVD230 本身也只保证经典 CAN 的速率范围。

USB-C 的 CC1、CC2 已使用 $5.1\ \mathrm{k\Omega}$ 下拉，设备角色配置正确；但 VBUS 没有接入或检测，D+、D− 也没有 ESD 保护和差分布线约束。STM32F042 的 USB FS 收发器已经集成所需的匹配阻抗，不应把缺少外置串联终端电阻单独列为错误。当前只能把它定义为尚待验证的自供电 USB 数据接口，不能宣称已经完成受控阻抗与接口保护设计。

## 4. 三相逆变与栅极驱动

### 4.1 三相桥的实际输出

Q1～Q6 组成三个半桥，每个半桥由一颗上管和一颗下管构成，三个中点分别连接三根电机相线。STM32G431 输出互补 PWM，FD6288T 驱动对应的上、下桥臂。

三相桥输出的相电压本身是高速切换的 PWM 脉冲，不是直接生成的平滑正弦电压。电机绕组具有电感，控制算法通过调整各相占空比，使绕组中的基波电流接近所需的正弦波形并形成旋转磁场。

同一半桥的上、下管不能同时导通，否则会把 `PVCC` 直接短接到功率地。FD6288T 内部带有互锁，死区范围为 100～300 ns、典型值约 200 ns，但 MCU 的 PWM 配置、器件传播延迟和实际开关波形仍需要用示波器确认。

### 4.2 MOS 管是不是“5 V MOS”

当前 MOS 管型号为 HYG080N10LS1C2。它的漏源耐压标称为 100 V；数据手册给出的导通电阻约为：$V_{GS}=4.5\ \mathrm{V}$ 时典型值 $9.4\ \mathrm{m\Omega}$、最大值 $13\ \mathrm{m\Omega}$，$V_{GS}=10\ \mathrm{V}$ 时典型值 $6.9\ \mathrm{m\Omega}$、最大值 $8.2\ \mathrm{m\Omega}$。这说明它属于可以用较低栅源电压驱动的逻辑电平 MOS 管，但提高到合适的栅压仍能进一步降低导通损耗。

但“5 V MOS”不是一个严谨的说法，需要区分三个概念：

- $V_{GS(th)}$ 只表示 MOS 管刚开始出现很小漏极电流时的阈值，不能用来判断它是否已经充分导通；
- 数据手册在哪个 $V_{GS}$ 下给出导通电阻，才说明该栅压是否属于有效驱动条件；
- 栅极驱动器使用 5 V 供电，不代表 MOS 管工作时一定得到精确的 5 V 栅源电压。

器件标注的 65 A 也不是整块板能够持续输出 65 A。实际电流还受 MOS 损耗、PCB 铜皮、连接器、分流电阻、散热方式和环境温度限制，必须通过热设计和实测确定。

原文中“逻辑电平 MOS 管抗 $\mathrm{d}v/\mathrm{d}t$ 能力极差”的结论也过于绝对。误导通风险与米勒电荷、阈值电压、栅极回路阻抗、驱动器下拉能力、开关速度和 PCB 布局共同相关，不能只由“逻辑电平”这一项判断。

### 4.3 FD6288T 与 5 V 栅极驱动

U2 的电源 `VCC` 接 5 V。R15～R20 是 $10\ \Omega$ 栅极串联电阻，这个数值只能作为起始值，后续仍要结合栅源波形、漏源尖峰、开关损耗和 EMI 调整。R9～R14 是预留的栅源下拉位置，但当前工程的 Value 属性为空，不能确认最终装配阻值；如果这些位置没有实际贴装，驱动器掉电时就缺少明确的栅源泄放路径。

对下桥臂而言，栅极高电平大致接近驱动器的 VCC，但还要扣除驱动器输出级压降，所以实际 $V_{GS}$ 不会始终等于 5 V。

更关键的问题是 FD6288T 的推荐 VCC、VBS 范围从 5 V 开始，VCC 与 VBS 的欠压锁定上升阈值均可能达到 5.0 V。当前一级降压的标称值只有约 4.99 V，再考虑反馈基准、电阻误差和纹波，低侧供电已经无法保证越过最坏情况下的启动阈值。驱动器输出级压降则会在此基础上进一步降低 MOS 管实际得到的栅源电压，但它不是 VCC 欠压锁定的原因。

因此，5 V 在当前设计中不是优势，而是一个需要修改的边界条件。

### 4.4 自举电路的正确理解

D2～D4 和 C38～C40 为三个上桥臂建立浮动电源。下桥臂导通、相节点接近地时，自举电容通过二极管充电；上桥臂需要导通时，驱动器把这个电容作为相对于 `VS` 节点的浮动电源。

自举电压近似为：

$$
V_{BS}\approx V_{CC}-V_D
$$

如果 VCC 为 5 V，扣除二极管压降和自举电容下垂后，$V_{BS}$ 会低于 5 V；“约 4.7 V”只能作为理想化示意，不能作为保证值。上管实际的 $V_{GS}$ 还会再扣除驱动器输出级的动态压降。这里讨论的电压都以 `VS`、也就是上管源极为参考，不是上管栅极对地只有 4.7 V。上管导通后，相节点会上升，栅极对地电压也会随之上升到约 $V_S+V_{GS}$。

自举电路本身不是把 5 V 变成更高的 $V_{GS}$，它只是让上桥臂得到一个跟随相节点移动的浮动电源。而且自举电容需要周期性刷新，不能保证上桥臂无限期保持 100% 占空比。

当前设计还有两个问题：

1. 自举后的 $V_{BS}$ 比 5 V 更低，已经落在 FD6288T 推荐工作下限附近，存在上桥臂欠压锁定或驱动不充分的风险；
2. D2～D4 使用 40 V 的 1N5819W。当母线接近 40 V 时没有任何反向耐压余量，叠加开关尖峰后不可靠。

下一版更合理的方案是为栅极驱动单独提供约 8～12 V 电源，同时保留 5 V/3.3 V 作为逻辑电源；或者更换为明确支持低压栅极供电的驱动器。不能直接把现有公共 5 V 提高到 8～12 V，因为 MP20051 的输入和其他 5 V 器件无法承受该电压。

## 5. 模拟采样

### 5.1 两电阻相电流采样

当前使用 R8、R21 两个 $10\ \mathrm{m\Omega}$ 低侧分流电阻采集两相电流，第三相电流根据三相电流和为零重构：

$$
i_a+i_b+i_c=0
$$

STM32G431 的内部运放配合外部 $2\ \mathrm{k\Omega}$ 与 $16\ \mathrm{k\Omega}$ 电阻构成约 8 倍增益。R40、R41 将 `AVCC` 分压得到中点参考：

$$
V_{REF}=\frac{AVCC}{2}\approx1.636\ \mathrm{V}
$$

分流电阻上的电流变化经过放大后，输出相对中点的变化量为：

$$
\Delta V_{OUT}=8\times10\ \mathrm{m\Omega}\times I
=0.08I
$$

也就是每 1 A 相电流对应约 80 mV 的 ADC 电压变化。按 3.272 V 电源进行理想计算，理论范围约为 $\pm20.4\ \mathrm{A}$；实际还要给内部运放和 ADC 留出上下端余量，因此可用范围会更小。

R8、R21 的额定功率为 1 W。仅按 $P=I^2R$ 计算，10 A 时每颗分流电阻就已经耗散 1 W，因此连续测量能力还会先受到分流电阻温升和 PCB 散热限制，不能按 ADC 的理想满量程直接宣称可持续测量 20 A。

`VCC_REF` 当前只由两个 $2\ \mathrm{k\Omega}$ 电阻分压产生，没有单独的旁路电容。这个参考点的噪声会同时进入两路电流采样，下一版应结合内部运放要求增加合适的滤波或缓冲，并验证启动时间和采样建立时间。

低侧分流电阻不是在所有 PWM 状态下都能得到有效相电流。当占空比接近极限值时，有效采样窗口会缩短，软件必须把 ADC 触发放在合适的开关状态中，并考虑运放建立时间和 ADC 转换时间。这属于两电阻低侧采样本身的约束，不代表电路完全无法工作。

### 5.2 母线电压采样

R39 为 $33\ \mathrm{k\Omega}$，R38 为 $2\ \mathrm{k\Omega}$，两者把 `PVCC` 分压到 `ADC_DCBUS`：

$$
V_{ADC\_DCBUS}=PVCC\times\frac{2}{33+2}
=\frac{PVCC}{17.5}
$$

例如母线为 40 V 时，ADC 引脚电压约为 2.286 V。按 3.272 V 满量程反推，分压比例对应的理想母线上限约为 57.3 V，但这只是 ADC 分压网络的量程，不能据此认为整块板可以承受 57.3 V。

如果把母线提高到 100 V，ADC 引脚将达到约 5.71 V，已经明显超过 MCU 模拟引脚范围；R39 上的耗散也接近 0.27 W，并承受约 94 V 压差，可能同时超出小封装电阻的额定功率和工作电压。若下一版提高母线等级，我需要重新设计分压比，使用多颗串联电阻分摊电压和功耗，并增加合适的 ADC 钳位保护。

C32 的 $100\ \mathrm{nF}$ 电容与分压电阻构成低通滤波，用于抑制母线开关噪声。

### 5.3 MOS 与电机温度采样

板载 MOS 温度采样使用 R34 的 $10\ \mathrm{k\Omega}$ NTC 和 R35 的 $3.3\ \mathrm{k\Omega}$ 下拉电阻：

$$
V_{ADC\_MOSFET}=AVCC\times\frac{R35}{R34+R35}
$$

在 25 ℃、NTC 约为 $10\ \mathrm{k\Omega}$ 时，ADC 电压约为 0.812 V。温度升高后 NTC 阻值下降，因此该 ADC 电压会上升。

`ADC_MOTER` 接口采用相似的分压方式，用于连接外部电机 NTC。这里的 `MOTER` 是拼写错误，下一版应统一改为 `ADC_MOTOR`。软件换算温度时必须使用实际 NTC 的标称阻值、B 值和分压电阻，不能直接照搬板载 NTC 的换算参数。

## 6. 当前版本的主要问题

以下问题按修改优先级整理：

| 优先级 | 问题 | 影响 | 下一版处理 |
| --- | --- | --- | --- |
| P0 | U1 的 VDDA 所在 `3V3` 网络悬空 | 板载调试器工作异常或不稳定 | 接入有效电源并增加本地去耦 |
| P0 | U1 与 U4 缺少独立可用的 SWD 救砖接口 | 板载调试器异常后难以重新烧录两颗 MCU | 为两颗 MCU 增加 SWD 测试焊盘或接口 |
| P0 | U14、U15 裸露焊盘未接地，输出电容不符合要求 | 3.27 V 电源可能振荡、启动异常或过热 | 按数据手册重画 LDO 周边电路和焊盘 |
| P0 | U15 输入电容 C29 返回了 `DGND` | U15 高频回流跨地网连接 | 改为就近返回 `AGND` |
| P0 | FD6288T 仅用约 5 V 供电 | 驱动与欠压锁定余量不足，尤其是上桥臂 | 增加独立 8～12 V 驱动电源或更换驱动器 |
| P0 | 自举二极管只有 40 V 耐压 | 高母线电压及尖峰下可能击穿 | 更换为具有足够反向耐压和速度的器件 |
| P0 | R9～R14 栅源下拉阻值未定义 | 装配结果不确定，掉电时栅极可能悬空 | 在原理图和 BOM 中明确阻值并实测验证 |
| P0 | U2 的 COM 与 C41 回到 `DGND` | 低侧栅极脉冲电流跨 R1 回到功率源极，可能造成参考地跳动 | 改为短、低感的 Kelvin 路径回到低侧源极/功率地 |
| P0 | 没有硬件过流关断 | 软件来不及处理短路、直通等快速故障 | 增加比较器、驱动器关断或硬件 OCP 链路 |
| P0 | 输入无保险、反接、TVS 和浪涌限制 | 接线错误和母线瞬态可能造成大面积损坏 | 增加输入保护并重新确定母线等级 |
| P0 | 八颗母线电容的图面值与料号相差 10 倍 | 容量、纹波和母线尖峰评估全部失真 | 统一 Value、料号和实装值后重新计算 |
| P1 | U4 模拟参考去耦不足且跨层放置 | ADC 噪声和参考电压稳定性变差 | 补充电容并缩短 VREF+/VSSA 回路 |
| P1 | MA600 缺少明确的本地去耦 | 角度采样可能受电源与开关噪声影响 | 按数据手册补充模拟、数字去耦 |
| P1 | MA600 的 AVDD 参考 `AGND`、GND 却接 `DGND` | 模拟供电回流跨过 R2 | 统一传感器供电与回流参考地 |
| P1 | MA600 靠近分流电阻和高电流路径 | 电流产生的磁场可能造成角度非线性 | 调整功率回路或传感器位置 |
| P1 | CAN 固定接入 120 Ω，CAN/USB 无 ESD | 拓扑适应性和接口抗扰度较差 | 终端改为可选并补充接口保护 |
| P1 | CAN、USB 的差分规则缺失或对象选错 | 高速信号回流和阻抗缺少约束 | 重设 `CAN_H/L` 与 USB D+/D− 规则 |
| P1 | 没有母线能量泄放或制动电路 | 快速减速、外力拖动时母线可能过压 | 根据电源是否能够吸收回馈能量增加制动方案 |
| P1 | 地分区依赖实际 PCB 回流路径 | 布局不当时 ADC 和 MCU 仍会受到功率噪声影响 | 结合电流环路重新检查铺铜和连接点 |
| P1 | 缺少关键电源、ADC、相节点和通信测试点 | 故障发生后难以区分电源、控制与功率级问题 | 在安全间距允许的位置增加测试焊盘 |

当前 `NFAULT` 只是 U4 上的单焊盘孤网，没有任何器件驱动它；固件中的 TIM1 DeadTime 目前为 0，Break/Break2 也处于关闭状态。因此，当前总死区完全由 FD6288T 内部决定，需要根据实测上下管栅极波形确认是否合适；同时也没有硬件故障信号能够直接关断 PWM。下一版增加 OCP 时，应把比较器或驱动故障信号接入定时器 BKIN，而不是只增加一个普通 GPIO 告警。

其中需要区分两个不同的问题：

- 电机堵转会引起大电流，主要依靠限流和硬件过流保护处理；
- 快速减速或电机被外力拖动会产生回馈能量，可能抬高母线电压，主要依靠可吸收能量的电源、制动电阻或其他母线钳位方式处理。

不能把“没有刹车电路”和“堵转后 MOS 管过流”当成同一个问题。

## 7. 上电与调试原则

当前版本存在已知电源问题，上电时我需要按电源树逐级确认，而不是直接接入电机母线：

1. 断电测量 `PVCC`、5 V、`DVCC`、`AVCC` 对各自地的阻值，发现低阻短路时不得继续通电；
2. 首次使用限流电源，从低母线电压、小电流限制开始，先确认 5 V，再确认两路 3.27 V；
3. 外部给 `DVCC` 或 `AVCC` 注入电源前，必须确认不会反向灌入仍连接着的 MP20051 输出；
4. 在不接电机和高压母线的条件下确认 MCU、调试接口与六路 PWM 逻辑；
5. 使用低母线电压检查栅源波形、死区、自举电压和相节点尖峰，再逐步提高电压；
6. 功率级调试必须同时设置电源限流、软件限流和安全停机条件，当前版本不能把软件保护当作唯一保护。
