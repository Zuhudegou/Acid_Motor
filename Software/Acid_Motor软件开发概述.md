# 关于控制
我将控制算法简单分为几点来说
1. 控制方法
	- 无感控制
		首先 我将无刷电机控制简化下 可以简单理解为 无刷电机控制 就是在做***电角度***与***物理转子角度***的同步 无感控制 顾名思义 无角度感应 全靠数学模型来猜测转子位置 可以分为以下几种方法 他们各有不同
		- 滑膜观测
			在 FOC 矢量控制中，三相线圈一直通电 无法利用**悬空相**来直接测出反电动势 滑模观测器的***本质*** 是 用已知的驱动电压和测得的实际电流，在算法内重建一套相同的定子电路方程，模型使用已知的驱动电压、电机参数（电阻、电感）以及实时采样的电流，对电机电流进行估算，并将估算电流与实际测量电流进行比较。当两者存在误差时，滑模控制项会根据误差方向快速切换并不断修正模型，使估算电流逐渐逼近实际电流。当观测器进入滑模状态（就是电机模型已经和实际电机同步转动）后，估算电流与实际电流基本一致，此时滑模控制项 经过**低通滤波**处理（非常重要 因为滑模控制项本身不是反电动势，而是一个高速开关信号；它的平均值才等于反电动势）便收敛为电机反电动势的估计值
			在静止 α−β 坐标系下，真实电机的电压微分方程为
			$$\frac{dI_\alpha}{dt} = -\frac{R}{L}I_\alpha + \frac{1}{L}U_\alpha - \frac{1}{L}E_\alpha$$
			根据上述算法 我简单定义一个观测电流${I}_\beta$ 输入电压$U_\beta$ 控制项${E}_\beta$ 
			可简单写出控制电流误差
			$$e_iss = {I}_\beta - I_\alpha$$$$\frac{de_iss}{dt} = -\frac{R}{L}e_iss + \frac{1}{L}(E_\alpha - E_\beta)$$
			我们的核心目的 是进入滑膜状态 也就是$e_iss$ 趋近于0
